# Python for Data Analytics Lab
## Experiments 1 to 3

This repository contains self-written Python programs based on the first three Data Analytics laboratory experiments.

### Experiment 1 - NumPy and Pandas Basics
- NumPy array creation and operations
- Mean, maximum and minimum
- Array indexing and slicing
- Pandas DataFrame creation
- DataFrame indexing, slicing and filtering

### Experiment 2 - Exploratory Data Analysis (EDA)
- Loading a CSV dataset
- Dataset information
- Descriptive statistics
- Identifying missing values
- Identifying duplicate records

### Experiment 3 - Data Visualization
- Histogram
- Box plot
- Scatter plot
- Pair plot
- Correlation heatmap

### Requirements
Install the required libraries using:

pip install numpy pandas matplotlib seaborn

### How to run
Open the required experiment folder and run its Python file.

Experiment 2 and Experiment 3 use:
student_performance.csv
